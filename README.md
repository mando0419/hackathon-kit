# hackathon-kit

AI 코딩 에이전트(Codex)로 웹 과제를 진행할 때 쓰는 **작업 규칙과 문서 템플릿 모음**입니다.
특정 과제의 답이나 코드는 들어 있지 않습니다.

## 구성
- `AGENTS.md` : 에이전트 작업 규칙 템플릿 (프로젝트 루트에 복사해서 포트 등만 수정)
- `templates/PLAN.md` : 요구사항·마일스톤 계획 문서 틀
- `templates/NOTES.md` : 설계 결정 기록 틀
- `templates/REQ_CHECK.md` : 요구사항 대조표 틀
- `prompts.md` : 단계별 프롬프트 모음

## 사용법
```
git clone https://github.com/mando0419/hackathon-kit /tmp/kit
```
프로젝트 폴더 밖(/tmp 등)에 받아서 필요한 파일만 복사합니다.
